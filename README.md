## Project Overview

GearGuard is a full-stack Maintenance and Asset Management System built to help organizations manage assets, vendors, maintenance schedules, logs, notifications, and dashboards in a secure and structured way.

The project follows real-world backend architecture practices with secure authentication and a scalable frontend design.

---

## Core Features

### Authentication & Security
- User registration and login
- JWT-based authentication
- Token expiry handling
- Role-based access control (Admin / User)
- Fully protected APIs

### Asset Management
- Create and manage assets
- Asset categorization
- Asset status and lifecycle tracking

### Maintenance Management
- Maintenance scheduling
- Maintenance logs
- Vendor assignment
- Cost tracking

### Notifications
- Maintenance reminders
- User-specific notifications
- Unread and read notification handling

### Dashboard
- Total assets overview
- Upcoming and completed maintenance
- Maintenance cost summary
- Aggregated system statistics

---

## Tech Stack

### Backend

### Frontend
- React
- Component-based UI
- API-driven architecture

- Postman for API testing

GearGuard demonstrates a secure, scalable, and production-ready backend combined with a modern frontend architecture. The project reflects real-world development practices and is suitable for maintenance and asset management use cases.
